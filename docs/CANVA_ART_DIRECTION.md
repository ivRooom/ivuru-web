# Canva Character Art Direction

正式キャラクターの導入前に、Canvaで生成した4つの方向性候補を比較するための選定基準です。

## 目的

- ivuruのDeveloper / Gamer / Communityを一つの人物像として表現する
- 現在の信号UIへ自然に重ねられる、商業品質のアニメキャラクターを決める
- PC Hero、スマートフォン、Profile、OG画像へ展開できる基準デザインを作る

## 必須条件

- 既存アニメ、ゲーム、VTuber、配信者のキャラクターに似ていない
- デフォルメやマスコットではなく、若い成人として描かれている
- シルバーから白の髪と、シアンの反射光を持つ
- 青、白、ディープネイビーを基調とし、紫はアクセントに限定する
- Developer要素を細い回路、端末、ホログラムなどで表現する
- Gamer要素をコントローラーの直描きだけに依存せず、動きや視線で表現する
- Community要素として、冷たすぎず話しかけやすい表情を持つ
- 16:9では人物を右側へ配置でき、左側にHero文章の余白を確保できる
- 9:16へ切り出しても顔と上半身が欠けない
- 背景を除去した透過PNGへ展開しやすい輪郭を持つ

## 避ける表現

- 動物耳、学生服、過剰な装甲、巨大な武器
- 既存作品を連想させる髪型、衣装、アクセサリー
- AI生成特有の細部崩れ、指や装飾の不整合
- 画面の大半を占める読めない文字や架空UI
- 小さな画面で潰れる過剰な装飾
- キャラクターより背景の情報量が強い構図

## 選定後の作業

1. 選定候補をCanvaデザインとして確定する
2. 顔、手、衣装、左右差、アクセサリーを手作業で補正する
3. Hero用透過PNGを`ivuru-hero-character-v2.png`として書き出す
4. 必要に応じてProfile用の正方形トリミングを作成する
5. 新しい画像URLを使用する実装PRを作成する
6. PC / Tablet / MobileのVisual Regressionを確認する
7. 承認後に信号キービジュアルと正式キャラクターを段階的に統合する

正式素材が承認されるまで、サイトは画像に依存しない信号UIを使用します。
